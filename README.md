# Uni Notes Website

> A web project within the University Notes ecosystem.

## Overview

This project is focused on providing a web-based experience for University Notes and related student learning services.

## Project Goals

- Make student learning resources accessible through the web
- Provide a simple and professional interface
- Support the wider University Notes ecosystem
- Continue improving the experience as the project develops
